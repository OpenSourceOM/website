# OpenSourceOM

**Open-source cloud security with a graph that shows what actually matters.**

OpenSourceOM maps cloud assets, identities, and exposures into a queryable security graph — so teams prioritize vulnerabilities and misconfigurations on real attack paths, not endless alert queues.

## Repositories

| Repo | Description |
|------|-------------|
| [website](https://github.com/OpenSourceOM/website) | Marketing site and documentation |
| [core](https://github.com/OpenSourceOM/core) | Platform — collectors, graph engine, API (in development) |

## Why OpenSourceOM?

- **Graph-native** — attack path analysis, identity blast radius, exposure-aware prioritization
- **Multi-cloud** — AWS, Azure, GCP (Kubernetes connectors planned)
- **Self-hosted** — run in your VPC, audit the code, Apache-2.0 licensed
- **Transparent** — no black-box risk scores
